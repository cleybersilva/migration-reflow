# Operação — preparação

Execute `uv sync` e `git config core.hooksPath .githooks` na raiz.
Os comandos funcionais do pipeline serão implementados nas próximas fases.
Se o hook indicar gates indisponíveis, não o desabilite: conclua as implementações.
Não use dados internos antes da conclusão e validação da camada de segurança.
